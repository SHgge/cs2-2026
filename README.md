# «Сургуулийн аварга – CS2 2026» — онлайн портал

Octolearn London School-ийн 8–12-р ангийн Counter-Strike 2 тэмцээний мэдээлэл, ангийн багийн бүртгэл, ил тод сугалаа, хуваарь, оноо.

- Зохион байгуулагч: А.Мөнгөншагай, утас 60114971, 94741053. Хүсэлт, асуултаа зохион байгуулагчид хандана уу.
- Тэмцээн: 2026.10.24 (Бямба) – 2026.10.25 (Ням).
- Гол хугацаа (SPEC v5): сугалаа 10.22 (Пү) 16:00; зөвшөөрөл (05, 05б), цаасан маягт 04, багийн хураамж 120 000 ₮ — 10.23 (Ба) 17:00; онлайн бүртгэл = бүрэлдэхүүн царцах 10.23 (Ба) 23:59 (migration 12).
- Шагналын сан 1 200 000 ₮ (600 000 / 360 000 / 240 000 ₮) + MVP 100 000 ₮; бүх хураамж шагналд зарцуулагдана.

- Сайт: **https://shgge.github.io/cs2-2026/**
- Сургуулийн гол (лобби) дэлгэц: **https://shgge.github.io/cs2-2026/#/screen** — бүтэн дэлгэцийн урам зориг өгөх постер; тоолуур, бүртгэлийн явц, сугалаа, тэмцээний үеийн оноо өөрөө шинэчлэгдэнэ. USB-ээр тоглуулах MP4/PNG: төслийн `14_Delgets/` хавтас (`_build/screen_export/export.mjs`).
- Статик сайт: `docs/` (GitHub Pages, build алхамгүй, цэвэр HTML/CSS/ES modules).
- Backend: Supabase-ийн тусгаарласан `cs2` схем; браузер зөвхөн `public.cs2_*` RPC функцуудыг дуудна.

## Хувийн мэдээлэл
- Нийтийн хуудсанд зөвхөн ангийн нэр, хуваарь, оноо харагдана.
- Тоглогчдын нэр зөвхөн тухайн ангийн QR холбоос болон зохион байгуулагчийн самбарт харагдана.
- Энэ repo-д нууц түлхүүр, тоглогчдын мэдээлэл **байхгүй**. `docs/js/config.js`-ийн түлхүүр нь нийтэд зориулагдсан publishable түлхүүр.
- Мэдээллийг устгах хуваарь:
  - 11.01 — шууд дамжуулалттай холбоотой мэдээлэл;
  - 12.31 — бүх хувийн мэдээлэл.

## Хөгжүүлэлт
```bash
npm test                          # логикийн тест (node --test)
npm run serve                     # http://localhost:8080 дээр сайтыг үзэх
node scripts/bump-version.mjs     # кэш шинэчлэх хувилбар
node scripts/prepush-check.mjs    # push-ээс өмнө нууц/хувийн мэдээлэл шалгах
git push                          # GitHub Pages ~1 минутад шинэчлэгдэнэ
```
- Өгөгдлийн сангийн migration-ууд: `supabase/migrations/` (12 — v5 нэр, хугацаа).
- Сургуулийн мэдээлэл: `docs/js/config.js`; тэмцээний нэр, хугацаа, хураамж, шагнал: `docs/js/event.js`.
- Лого: `docs/assets/img/logo-{64,192,512}.png`.
- SQL тестүүд: `supabase/tests/` — `BEGIN … ROLLBACK` дотор ажиллана.
- Нийтлэг гэрээ (API, логик, файл эзэмшил): `CONTRACT.md`.
